目前完成：**高一上數學 3.4**。

## 這一版為什麼改成多檔案？

3.2 是單一 HTML 原型，方便下載後測試；3.3 把畫面、程式與資料拆開：

```text
.
├─ index.html
├─ math.html
├─ .nojekyll
├─ START_LOCAL.bat
├─ assets/
│  ├─ css/
│  │  └─ math.css
│  └─ js/
│     └─ math-app.js
└─ data/
   └─ math/
      ├─ config.json
      ├─ units.json
      ├─ mindmaps.json
      ├─ similar.json
      ├─ exam1.json
      ├─ exam2.json
      └─ exam3.json
```

之後新增題目時，原則上改 JSON 即可，不必把整個 HTML 改掉。

## GitHub Pages 部署（最簡單）

1. 在 GitHub 建立一個 repository，例如 `high-school-learning`。
2. 把這個資料夾內的**所有檔案與資料夾**放到 repository 根目錄。
3. Commit / Push 到 `main` branch。
4. GitHub repository → **Settings → Pages**。
5. `Build and deployment` 的 `Source` 選 **Deploy from a branch**。
6. Branch 選 `main`，folder 選 `/(root)`，按 **Save**。
7. 發布網址通常是：
   `https://你的帳號.github.io/high-school-learning/`

如果 repository 名稱就是 `你的帳號.github.io`，則網址會是：
`https://你的帳號.github.io/`

本專案已包含空白 `.nojekyll`，讓 GitHub Pages 直接發布靜態 HTML/CSS/JS/JSON。

## Windows 本機預覽

因為 3.3 題庫用 `fetch()` 讀取 JSON，瀏覽器通常不允許直接用 `file://` 雙擊 HTML 讀取資料。

如果電腦已有 Python：

- 雙擊 `START_LOCAL.bat`
- 瀏覽器開啟 `http://localhost:8000/`

或在專案資料夾執行：

```bash
python -m http.server 8000
```

## GitHub Pages 的限制

GitHub Pages 是靜態網站，因此瀏覽器中的「題庫管理」**不會直接改 GitHub repository 的檔案**。

正確流程：

1. 在 `manager.html` 編輯題庫。
2. 按「匯出目前段考 JSON」。
3. 假設你編輯第一次段考，下載檔會是 `exam1.json`。
4. 用這個檔案覆蓋 repository 裡的 `data/math/exam1.json`。
5. Git commit / push。
6. GitHub Pages 重新部署後，學生網站就會讀到新題庫。

這種做法不需要把 GitHub Personal Access Token 寫進公開網頁，因此更安全。

## 語音導讀設計
不是整頁朗讀。以下學習重點框會在右上角自動出現 `🔊`：
- 今日任務核心說明
- 高手一句話

- 名詞解釋
- 題型「看到什麼／想到什麼」
- 完整例題說明
- 為什麼這樣做
- 快解與陷阱
- 舊知識回憶
- 生活情境
- 30秒小結
- 階段整理
- 最終高手口訣
- 作答後較長的解題回饋

操作：
- `🔊`：開始朗讀
- `⏸`：暫停
- `▶`：繼續
- 點另一個框的喇叭：停止上一段，開始新段
- 切換關卡／頁面：停止原朗讀

語音：
- 使用瀏覽器 Web Speech API
- 優先選 `zh-TW` / 繁中語音
- 語速預設 `0.88`，比一般 TTS 稍慢
- 優先選裝置上的台灣中文／Mandarin自然語音
- 會把常見數學符號轉成較自然的朗讀，例如 `=` →「等於」、`+` →「加」、`m₁` →「m 一」、`1/2` →「二分之一」
- 隱藏中的答案／尚未揭露例題步驟不會被朗讀偷跑

限制：
GitHub Pages 靜態版使用學生裝置本身的語音引擎，因此實際音色取決於 Chrome／Edge／Safari 與作業系統已提供的中文語音。若未來要所有裝置都固定使用同一個高品質 Neural Voice，需要再串接雲端 TTS。

新版先用互動圖講：
- 圓上點 P 到圓心 C 的距離固定
- 水平差、垂直差如何形成直角三角形
- 距離公式其實就是畢氏定理
- 所以 `(x-h)^2 + (y-k)^2 = r^2` 不是憑空背下來

新增互動條：
- 圓心 `h`
- 圓心 `k`
- 半徑 `r`
- 圓上點角度 `θ`

拖曳後會即時更新：
- 圖上的圓
- 圓心與圓上點
- 半徑
- `x-h`、`y-k`
- 推導文字

### 2) 直線與圓（u08）加上「何謂距離」圖示
新版特別補上：
- 從圓心到直線可以畫很多條線段
- **只有和直線垂直的最短線段** 才叫距離 `d`
- 用不同灰色線段對比，凸顯橘色最短垂線段
- 另外畫一條獨立半徑，避免學生誤以為「距離」這個詞沒有標準

拖拉 `x=a` 的位置可直接看到：
- `d>r`：相離，0 個交點，0 組解
- `d=r`：相切，1 個交點，1 組解
- `d<r`：相交，2 個交點，2 組解

### 3) 相切性質明講「誰跟誰垂直」
這版不只寫「相切」，而是直接圖示：
- 切點 `T`
- 半徑 `OT`

- `OT ⟂ 切線`

並強調：
- 圓心到切線的距離，就是這條半徑
- 但畫面上另外保留一條獨立半徑，方便學生區分「半徑概念」與「距離定義」

# 5.3 拋物線參數角色＋根／區間全圖解版

## u11 二次函數：先把「誰會變、誰是固定設定」講清楚
### 第一層只研究 `a`
主互動只留下：
- `x`：輸入／位置，會變
- `y`：輸出／結果，會跟著變
- `a`：固定係數

學生先拖 `a` 看：
- `a>0`：向上
- `a<0`：向下
- `|a|` 越大：越窄
- `a=0`：不再是二次函數

### 第二層才看 `h、k`
固定 `a=1`：
- `h`：只搬左右
- `k`：只搬上下
- 頂點 `(h,k)`

### 第三層才看一般式 `y=ax²+bx+c`
避免一次塞三個 slider，改成「一次只研究一個」：
- `a`：開口方向與寬窄
- `b`：**不控制開口大小**；和 `a` 一起決定對稱軸 `x=-b/(2a)`
- `c`：`y` 軸交點 `(0,c)`

圖上同步標：
- 頂點
- 對稱軸
- `x` 軸交點（根）
- `y` 軸交點

### 拋物線與畢氏定理
特別區分兩條理解路線：
1. **高中二次函數核心**：從 `y=x²` 做伸縮與平移，得到 `y=a(x-h)²+k`
2. **幾何延伸**：拋物線定義為「到焦點與準線等距」。這條推導才會使用距離公式，而距離公式來自畢氏定理。

新增焦點—準線互動圖：
- 拖動拋物線上的點 P
- 顯示 `PF`
- 顯示 P 到準線的垂直距離
- 兩者始終相等

### 左右開口
放到「延伸」摺疊區，不和二次函數核心混在一起：
- `x=A(y-k)²+h`
- `A>0` 向右
- `A<0` 向左
- 說明此圖一般不是單一 `y=f(x)`，因此不是高中二次函數主線

### 最大最小生活題：教「翻譯」而不是只教頂點公式
統一流程：
1. 定義變數與單位
2. 把其他量用 x 表示
3. 建立關係（面積、收益、高度等）
4. 依題目資訊選頂點式／因式式／一般式
5. 最後才求最大或最小

## u12 三次函數與多項式不等式
主線改成：
**根 → 解 → x 軸交點 → 因式 → 圖形 → 區間正負**

### 根先講清楚
`r` 是根代表：
- `f(r)=0`
- `x=r` 是方程式的解
- 圖通過 `(r,0)`
- `(x-r)` 是因式

### 三次式不是硬解
示範：
`x³-6x²+11x-6`
→ 試出根 1
→ 提出 `(x-1)`
→ 降成二次式
→ 再分解成 `(x-1)(x-2)(x-3)`

### 重根圖解
新增切換：
- 一重根：穿過 x 軸、通常換號
- 二重根：碰 x 軸後折返、通常不換號

### 多項式不等式
新增逐因式區間表：
- 根先切數線
- 每一區分別看 `(x-r)` 的正負
- 最後把正負相乘
- `>0 / <0 / ≥0 / ≤0` 再決定是否包含根

### 文字應用
不再只丟一個模型，而是教：
1. 定義 x
2. 找文字裡的臨界值
3. 臨界值 r → 因式 `(x-r)`
4. 組成多項式
5. 題目說正值／負值 → 建立不等式
6. 因式分解＋號線求區間
